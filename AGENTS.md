# AGENTS.md — Автономный видеопайплайн Канала №3 (Kinetic Lab / HyperScale)

## 1. ПРОФИЛЬ КАНАЛА И ВИЗУАЛЬНЫЙ КОД
- **Проект:** **Kinetic Lab** (рабочие варианты: `HyperScale` / `Scale Paradox`) — англоязычный техно-научно-развлекательный YouTube-канал для аудитории США и Tier-1 (`RPM $11–18`).
- **Слоган:** *«Extreme engineering, physics, and impossible machines explained at full speed»*.
- **Ниша и формат:** «Американские эндорфиновые горки» (*Extreme-Pacing Science & Engineering*) — разбор невероятных машин, пределов физики, космоса, квантовых технологий и наноинженерии на высокой скорости без сухого академизма.
- **Голос TTS (`Kokoro-82M`):** `bm_george` (невозмутимый британский тембр), `speed=1.08`, `lang_code='b'`, 24kHz WAV.
- **Визуальная идентичность «High-Voltage Lab» (`src/labTheme.ts`):**
  - Фон: `#090A1A` (глубокий графитово-фиолетовый) с анимированной координатной сеткой и микрочастицами (`opacity: 0.12`).
  - Физика / Окружающая среда / Базовые данные: `#3B82F6` (неоновый электрический синий).
  - Инженерный прорыв / Решение: `#A3E635` (кислотно-лаймовый).
  - Критическая перегрузка / Предел физики / Опасность: `#F43F5E` (огненно-коралловый).
  - Текст и цифры: `#F8FAFC` (чистый белый) и `#94A3B8` (светло-серый).
  - Шрифты: `Space Grotesk` + `JetBrains Mono` (локальные `.woff2` в `public/fonts/`).
- **Обязательные React-компоненты (`src/components/`):**
  1. `<ScaleComparator />` — сравнение экстремальных масштабов (`0.015K` vs поверхность Солнца, ракета vs человек) с пружинным зумом (`spring`).
  2. `<StressGauge />` — скоростной датчик перегрузки (температура, давление, G-force, скорость) с динамическим заполнением и вспышкой красной зоны `#F43F5E`.
  3. `<MechanismBreakdown />` — пошаговая схема работы машины/процесса, где узлы и стрелки энергии вспыхивают по очереди.
  4. `<PulseTimeline />` — шкала экстремальных этапов с резкими световыми отсечками.
  5. `<HudOverlay />` — верхний и нижний лаконичный HUD-слой (счетчик раундов и динамические плашки `[BADGE]`).

## 2. АРХИТЕКТУРА СРЕДЫ И ОБЛАЧНЫЙ РЕНДЕР (ЖЕСТКИЕ ПРАВИЛА)
- **Рабочая директория и репозиторий:** `~/video-project/` (`https://github.com`, ветка `main`). Корень Remotion-проекта находится прямо здесь, отдельной папки `remotion-app/` нет.
- **Python-окружение нейросетей (WSL2):** Строго `~/kokoro/venv` (Python 3.12, `torch` CPU, `kokoro 0.9.4`, `whisperx 3.8.6`, `faster-whisper 1.2.1`, системный `espeak-ng 1.52.0`). Симлинк `~/kokoro-tts` → `~/kokoro`. Веса закэшированы локально в `~/.cache/huggingface` и `~/.cache/torch`. Системный `python3` (3.14) используется только для stdlib-скриптов.
- **Шрифты и медиа-ассеты:**
  - 13 локальных шрифтов `.woff2` лежат в `public/fonts/` и подключаются через `staticFile('fonts/...')` (подмены шрифтов в Linux CI не происходит).
  - Рабочие SFX и музыка лежат в `public/audio/sfx/` и `public/audio/music/` (папка `public/audio_bank/` не используется).
  - Генерация изображений (`scripts/generate_image.py` через Pollinations `flux.1-schnell`) использует `POLLINATIONS_API_KEY` из `.env`.
- **Разделение вычислений (Ноутбук vs Облако):**
  - **На локальном ПК (WSL2)** выполняется ТОЛЬКО парсинг сценария, генерация речи (`Kokoro`), нормализация (`ffmpeg`), транскрибация (`WhisperX`), генерация JSON-данных и при необходимости статичных обложек (`out/thumb_A/B/C.png`).
  - **В облаке (GitHub Actions — `.github/workflows/render.yml`)** выполняется финальный рендер видео (`MainVideo` 1920x1080 60fps, `Short1–3` 1080x1920 60fps) на раннерах `ubuntu-latest` (Node 22) параллельными jobs с флагами `--gl=swangle --concurrency=4 --codec=h264 --crf=18`.
  - **КАТЕГОРИЧЕСКИ ЗАПРЕЩЕНО** запускать локальный рендер полных видеофайлов на ноутбуке (нет GPU). Для передачи данных в GitHub Actions все аудио, субтитры и ассеты коммитятся в Git (размер любого файла строго `< 95 MB`).

## 3. АРХИТЕКТУРА «ЭНДОРФИНОВЫХ ГОРОК» (ROLLERCOASTER PACING)
- **Воронка «1 Long + 3 Shorts»:**
  - Основное видео (`MainVideo`, `16:9`): строго **8:20 – 9:15 минут** (~1380–1480 слов в блоках `VOICE:`) для полноценной mid-roll монетизации YouTube и целевого APV 60%+.
  - 3 вертикальных Shorts (`Short1`, `Short2`, `Short3`, `9:16`): **35–42 секунды** каждый (95–105 слов) в конце единого файла `script.md`.
- **Структура основного ролика (Тройной хук + 4 раунда по ~2 мин + Финал по Зейгарник):**
  1. **`[HOOK]` (0:00–0:20):** Без приветствий. Сразу шок-контраст масштабов, смена состояния экрана каждые **2.0–2.5 сек**.
  2. **`[CLIMB]` (Подъем — начало раунда, ~45 сек):** Фразы по 12–15 слов, спокойная постановка физического парадокса через бытовую аналогию. Смена визуала каждые **5–6 сек**.
  3. **`[ACCEL]` (Ускорение — середина раунда, ~45 сек):** Фразы по 7–10 слов, нагнетание цифр, давления, скорости и цены ошибки. Смена визуала каждые **3–4 сек**.
  4. **`[DROP]` (Спуск — кульминация раунда, ~30 сек):** Телеграфная подача (3–6 слов в предложении). Стыки между фразами в аудио сжимаются до `0.12–0.15s`. Перед главной цифрой раунда ставится явная пауза `[SILENCE 0.5s]` (30 кадров при 60fps), в конце раунда — басовый удар `[J-CUT SFX: sub-drop]`. Калейдоскоп визуала каждые **1.5–2.5 сек**.
  5. **Финал по Зейгарник (Scene 24):** Главный инсайт за 15 секунд и мгновенный бесшовный мост на следующий парадокс канала без прощаний.

## 4. ПРАВИЛА ФОРМАТА `script.md`, ОБЛОЖЕК И БЕЗОПАСНОСТИ
1. **Разделение `META:` и `VOICE:` (Anti-TTS Bug):**
   - В `META:` указываются тайминг, фаза (`[HOOK]`, `[CLIMB]`, `[ACCEL]`, `[DROP]`), компонент High-Voltage Lab, плашка `[BADGE: 2-3 СЛОВА]`, `[SILENCE 0.5s]` и `[J-CUT SFX: ...]`.
   - В `VOICE:` передается **ИСКЛЮЧИТЕЛЬНО** чистый английский текст. Запрещены любые цифры (`350` → `three hundred fifty`), символы (`%`, `$`, `/`), скобки и теги, чтобы `Kokoro` не зачитал служебные символы.
2. **Визуальная плотность и 2D-скорость:**
   - Запрещены статичные кадры длиннее 6 сек в `[CLIMB]` и длиннее 2.5 сек в `[DROP]`.
   - Используется только легкий 2D SVG/React-рендер (запрещено добавлять `three` / `@remotion/three`).
   - Safe-zones: для `16:9` отступы `>= 64px`; для `9:16` Shorts `top >= 220px`, `bottom >= 380px`.
3. **A/B-обложки (`src/data/thumbnail_data.json`, 1280x720, максимум 3 элемента, 2–3 слова):**
   - `ThumbVariantA` («Невозможный масштаб»): гигантский объект против микроскопического / барьера.
   - `ThumbVariantB` («Красная зона»): разрез механизма с раскаленной зоной перегрузки.
   - `ThumbVariantC` («До / После»): сравнение провальной конструкции и инженерного взлома.

## 5. ПОШАГОВЫЙ ПАЙПЛАЙН СБОРКИ ВЫПУСКА
1. **Локальная подготовка (`./build_all.sh`):**
   - `scripts/parse_script.py` — парсит `script.md` на `public/scenes/manifest.json`, `public/audio/shorts/manifest.json` и чистые `voice/*.txt`.
   - `scripts/tts_manifest.py` — генерирует озвучку через `~/kokoro/venv/bin/python ~/kokoro/generate.py` (`bm_george`, `speed=1.08`).
   - `scripts/normalize_audio.sh` — нормализует звук через `ffmpeg loudnorm` до `-14 LUFS` (`TP=-1.0 dBTP`, `LRA=11`).
   - `scripts/concat_audio.py` — склеивает `public/full_audio.wav` с точными паузами `[SILENCE 0.5s]` и сжатием стыков `[DROP]` до `0.13s`.
   - `WhisperX` + `scripts/build_captions.py` + `scripts/build_timeline.py` — обновляет `public/subs/*.json`, `src/data/video_data.json` и `src/data/shorts_data.json`.
   - `npx tsc --noEmit && npx eslint src` — обязательная проверка типов и линтера перед отправкой.
2. **Облачный рендер (GitHub Actions):**
   - Проверка лимита файлов (`< 95 MB`) → `git add -A && git commit -m "feat(ep): release audio, subs and data" && git push origin main`.
   - Запуск workflow во вкладке **Actions** (`https://github.com/actions`) и скачивание готовых `main_video.mp4` и `short_1..3.mp4` из раздела **Artifacts**.
