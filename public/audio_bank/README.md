# Локальный банк музыки (YouTube Audio Library)

Складывай сюда скачанные MP3/WAV треки из YouTube Audio Library по папкам настроения:
- `tension/` — саспенс, расследования, финансовые кризисы (Канал №1)
- `tech/` — минималистичный техно-эмбиент, ритмичный пульс (Канал №2)
- `ambient/` — нейтральный документальный фон для длинных объяснений
- `sfx/` — короткие звуковые акценты (whoosh, hit, glitch, cash)

Чтобы агент увидел список доступных треков, он вызывает: `scripts/list_audio_bank.sh`
